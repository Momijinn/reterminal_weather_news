# reterminal_weather_news

このリポジトリは、 Seeed Studio から発売されている [reTerminal E1002reTerminal E1002](https://wiki.seeedstudio.com/ja/getting_started_with_reterminal_e1002/) で, 天気情報とニュースを表示するための Arduino アプリと Web アプリを提供します。

使い方やセットアップ手順については、各フォルダ内の README.md を参照してください。

## Folder Structure

- `arduino/`: reTerminal E1002 用の Arduino スケッチ
- `web/`: 天気情報とニュースを表示する Web アプリ
